# TSAR
Official PyTorch Implementation of ICASSP 2026 paper "TSAR: Scalable Time Series Forecasting Meets Next-Scale Autoregressive Modeling"

### Usage

1. Install Pytorch and other necessary dependencies.

   ```
   pip install -r requirements.txt
   ```

   

2. Train and evaluate model. We provide the experiment scripts under the folder ./script/. You can reproduce the experiment results as the following examples:

   ```
   bash ./script/ETTh1/ETTh1_192.sh
   ```
